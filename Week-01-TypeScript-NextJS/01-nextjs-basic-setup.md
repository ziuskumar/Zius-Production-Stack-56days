# 🚀 Next.js Basic Setup

## 📌 What is Next.js?

Next.js is a **React framework** used to build **full-stack, fast, and SEO-friendly web applications**.

---

## ⚡ Create a New Project

```bash
npx create-next-app@latest
```

### ✅ Recommended Options

- TypeScript → **Yes**
- Tailwind CSS → **Yes**
- App Router → **Yes**
- ESLint → **Yes**

---

## ▶️ Run the Project

```bash
npm run dev
```

🌐 Open: `http://localhost:3000`

---

## 🧩 First Page

```tsx
export default function Home() {
  return <h1>Hello Next.js</h1>;
}
```

---

## 🎯 Why Use Next.js?

- 📂 File-based routing
- ⚡ Fast performance
- 🔍 Better SEO
- 🖥️ Server-side rendering
- 🔌 API support
